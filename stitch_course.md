# Course Stitcher

Assembles a single long-scrolling HTML file from sections of three Harrell
online books, interspersed with images and arbitrary web pages, for linear
presentation during Zoom courses.  The R script-created HTML file is suitable
for viewing after magnifying the image to 200% because the device-responsive
HTML generated by Quarto in the original files re-wraps lines and drops
material in the margins upon magnification.  A chrome-based browser such as
`Brave` should be used so that regular text and math will be magnified by
the same amount (`Safari` does not accomplish this).

The `stitch_course` R script was developed interactively through an extended
dialog between Frank Harrell and `Claude AI`.  Harrell specified the tasks and
goals and performed extensive testing while `Claude` did all the coding.

## Books

| YAML key | Tab  | Full title                            | URL                        | Local mirror  |
|----------|------|---------------------------------------|----------------------------|---------------|
| `bbr`    | BBR  | Biostatistics for Biomedical Research | https://hbiostat.org/bbr   | ~/web/bbr     |
| `rms`    | RMS  | Regression Modeling Strategies        | https://hbiostat.org/rmsc  | ~/web/rmsc    |
| `rflow`  | RFlow| R Workflow                            | https://hbiostat.org/rflow | ~/web/rflow   |

Pages are read from local mirrors first (instant, works offline). If a local
file is not found the page is fetched from the network. Asset URLs (figures
etc.) are always rewritten to absolute hbiostat.org URLs in the output HTML
so the file is portable and self-sufficient on any server.

## Setup

Install R packages once:

    install.packages(c("httr2", "xml2", "yaml", "stringr", "base64enc"))

## Usage

    Rscript stitch_course.R                           # reads course_nav.yaml
    Rscript stitch_course.R my_session.yaml out.html  # custom files

Open the output HTML in any browser. The file is fully self-contained —
local images are base64-embedded — and can be hosted on a remote server.
Brave browser is recommended for best MathJax and zoom fidelity.

## YAML reference

### Top-level fields

    title: "Course Title"
    output_file: "out.html"

    # Single cover image displayed before the title block (base64-embedded)
    image: ~/path/to/cover.png

    # Multiple cover images before the title block
    images:
      - ~/path/to/first.png
      - ~/path/to/second.png

    # Presenter block centered below the title.
    # Use the YAML literal block scalar | to preserve line breaks.
    # Insert a line containing a single space to produce a blank line.
    presenters: |
      Frank Harrell PhD
      Department of Biostatistics, Vanderbilt University
     
      May 2026

    sessions:
      ...

### Session object

Each real session has a title and a list of sections:

    sessions:
      - title: "Session 1: Introduction"
        sections:
          - ...

Sessions appear in the floating table of contents. Images and webpages
placed between sessions (see below) do not appear in the TOC.

---

### Book section entry

    - book: rms          # bbr | rms | rflow
      include:
        - "4"            # entire chapter 4 and all its subsections
        - "5.1"          # section 5.1 and all its children
        - "5.4.2"        # exactly subsection 5.4.2
        - preface        # book index / preface page
        - intro          # chapter opening text before the first numbered section
      exclude:           # optional: remove sections from the included content
        - "4.3"          # removes section 4.3 even if whole chapter 4 is included
        - "5.1.2"        # removes a specific sub-section

**include keywords:**

| Spec      | What is fetched |
|-----------|-----------------|
| `"4"`     | Entire chapter 4 (chapter title + all subsections) |
| `"5.1"`   | Section 5.1 and all its children |
| `"5.1.3"` | Exactly subsection 5.1.3 |
| `preface` | Book index / preface page |
| `intro`   | Text before the first numbered section of a chapter |

**exclude:** Takes the same numeric spec format as include. Matched sections
are removed from the extracted HTML after collection. Unmatched specs produce
a warning and are silently skipped — they never cause errors.

Multiple `include` entries for the same chapter are resolved to a single page
fetch; all specs are applied together.

`include` and `exclude` can also refer to symbolic section tags such as `#sec-xxx-yyy`.

---

### Image slide entry

Full browser-frame width, 100vh spacing above and below, no TOC entry.
Local files are base64-embedded so the HTML is fully self-contained.

    - image: ~/path/to/slide.png    # local file or http/https URL
      caption: "Optional caption"   # optional

Supported formats: jpg, png, svg, gif, webp.
Local paths starting with `~` are expanded. Other local paths are relative
to the directory where you run `Rscript`.

---

### Webpage insert entry

Inserts an arbitrary HTML page with 25vh spacing above and below, no TOC
entry. A right-margin tab shows the label while the insert is in view.

    - webpage: ~/path/to/page.html  # local file or http/https URL
      libs: ~/path/or/url/assets    # optional: base URL for relative assets
      label: "My Page"              # optional: right-margin tab label

If `libs` is omitted, relative asset URLs in the page are left unchanged.
If `label` is omitted, the filename or hostname is used.

---

### Images and webpages between sessions

Image and webpage entries can appear as siblings of session objects in
the `sessions:` list, not only inside a session's `sections:`. They are
rendered between sessions but do not appear in the TOC.

    sessions:
      - title: "Session 1: ..."
        sections:
          - book: rms
            include:
              - "1"
      - image: ~/web/img/stop.png       # between sessions
      - image: ~/web/img/start.png
      - title: "Session 2: ..."
        sections:
          - book: rms
            include:
              - "2"

## Output features

| Feature | Detail |
|---------|--------|
| Floating TOC | Top-right panel, hideable with ✕; restored with ☰ |
| Book transition banner | Colored bar at each source change; shows short name, full title, link to original |
| Sticky margin tab | Small gray label on right edge tracks current book as you scroll |
| Section numbers | Original numbering preserved (content lifted as rendered) |
| Figures | Load live from hbiostat.org (internet required during presentation) |
| Math | Rendered via the books' own MathJax setup (tex-chtml-full.js) |
| Bootstrap/Quarto styling | Inherited from source books |
| Diagrams | Mermaid/Graphviz init scripts collected and injected |
| Audio clips | Removed from output |
| Margin annotations | Single-character red margin symbols removed from output |
| Local images | base64-embedded; output HTML is fully self-contained |
| Portability | Output can be opened directly or hosted on any web server |

## Zoom presentation tips

- Use Cmd+/Cmd− to adjust browser zoom for your display
- Use Cmd+F to jump to any section title
- Click ✕ in the TOC panel to hide it during presentation; ☰ restores it
- The sticky right-margin tab always shows which book is currently on screen
- 100vh spacing around image slides ensures book content is off-screen
  when an image is displayed
